# ДОМ АВТО

Информационный сайт об автомобилях из-за рубежа. Главная страница — `index.html`. Каталог, статьи и документы доступны без регистрации. Сборка сайта и установка зависимостей не требуются.

## Загрузить исходники на GitHub

1. Создайте репозиторий и распакуйте архив в его корень. `index.html` и папка `assets` должны находиться на одном уровне. Отдельный HTML для просмотра загружать не нужно.
2. Добавьте файлы через `Add file → Upload files` или обычным коммитом Git. Сохраните структуру папок, включая `blog` и `assets`.
3. Если будете размещать информационную версию на GitHub Pages, выберите `Settings → Pages → Deploy from a branch → main → / (root)`. [Настройка публикации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Перед запуском

- Проверьте, какие журналы ведёт выбранный хостинг, кто имеет к ним доступ и сколько они хранятся. При необходимости отразите эти сведения в `privacy.html`. Проверьте открытие страниц по HTTPS.
- В подвале есть политика конфиденциальности, политика использования cookie, условия использования сайта и настройки cookie. Баннер хранит выбор в браузере. При добавлении аналитики или рекламы обновите политику и настройте запуск скриптов после соответствующего выбора.
- Перед добавлением заявок, оплаты, заказов или коммерческого перенаправления уточните статус исполнителя, реквизиты, фактические цели и способы обработки персональных данных. Если применяется согласие, оформите его отдельно от иных подтверждаемых документов. Для рабочей коммерческой версии выберите хостинг, допускающий такое размещение.
